## Что внутри

Это русская переработка [danjdewhurst/story-skills](https://github.com/danjdewhurst/story-skills)
для **ChatGPT Work и Codex**. Все инструкции, справочники и примеры написаны
по-русски; названия папок сохранены для совместимости.

| Возможность | Как это работает |
| :--- | :--- |
| **Один навык или вся коллекция** | Каждая папка содержит всё необходимое для своего навыка. |
| **Контекст проекта** | Агент находит нужные главы, канон, планы, отзывы и образцы стиля среди доступных материалов. |
| **Русский текст** | Работа с авторским голосом, диалогом, пунктуацией, ритмом прозы и стихотворным размером. |
| **Разные среды** | Используются инструменты текущего сеанса; отдельный отрывок можно разобрать и без проекта. |

**Специальное ПО для обычной работы с текстом не требуется.** В репозитории нет
Story CLI, приложения, зависимостей или конфигурации плагина.

## Быстрый старт

Передайте агенту этот запрос — целиком или с названиями выбранных навыков:

```text
Установи навыки из https://github.com/Biryukovlex/story-skills-chatgpt-ru.
Следуй разделу «Инструкция для агента» в README.
Установи всю коллекцию, если среда поддерживает установку навыков.
Сохрани существующие навыки и сообщи, что установлено и как это вызвать.
```

Затем дайте конкретную задачу, например:

> Используй line-editing: бережно отредактируй главу, сохрани мой голос.
> Учти стилевой паспорт и соседние главы, если они доступны в проекте.

Если установка недоступна, переходите к [ручному использованию](#ручное-использование).
Само открытие репозитория или ссылка на него не устанавливают навыки.

## Установка

### Выберите среду

| Среда | Способ использования |
| :--- | :--- |
| **Codex: приложение, CLI, IDE** | Установите выбранные папки через доступный установщик навыков или в поддерживаемую локальную директорию. |
| **ChatGPT Work на компьютере** | Используйте доступный механизм навыков; если он не позволяет подключить папку, передайте материалы вручную. |
| **ChatGPT в браузере или на iPhone** | Используйте материалы вручную. Штатное подключение навыков на этих платформах поддерживается через плагины; эта коллекция пока не упакована в плагин. |
| **iPhone с Remote** | Можно продолжать работу на подключённом компьютере с его файлами, навыками и инструментами. |

Поддержка форматов и способы подключения описаны в официальной документации:
[навыки и плагины](https://learn.chatgpt.com/docs/build-skills),
[удалённое подключение](https://learn.chatgpt.com/docs/remote-connections).
Доступность конкретных функций зависит от клиента и текущего сеанса.

### Codex

Если доступен встроенный установщик, попросите его установить выбранные папки
из этого репозитория. Например, в Codex можно отправить **запрос**, а не команду терминала:

```text
$skill-installer установи line-editing и chapter-writing
из https://github.com/Biryukovlex/story-skills-chatgpt-ru,
из соответствующих папок внутри skills/.
```

При ручной локальной установке Codex поддерживает:

| Область | Куда поместить папки навыков |
| :--- | :--- |
| Для пользователя | `~/.agents/skills/<skill-name>/` |
| Для конкретного проекта | `<project>/.agents/skills/<skill-name>/` |

Например, файл одного установленного навыка будет находиться по пути
`~/.agents/skills/line-editing/SKILL.md`. Рядом должны остаться `agents/` и `references/`.
Установщик может использовать другую директорию, поддерживаемую текущей конфигурацией:
учитывайте её и не создавайте дубликаты без необходимости.

Для явного вызова в Codex используйте `$line-editing`, `$chapter-writing`
или другой установленный идентификатор. Если навык не появился, проверьте список
доступных навыков и при необходимости перезапустите клиент.

### Ручное использование

1. Выберите навык из [таблицы ниже](#все-навыки).
2. Откройте его `SKILL.md` и выберите справочники, подходящие задаче.
3. Приложите файлы к беседе или проекту либо передайте их содержимое текстом.
4. Попросите следовать инструкциям и укажите рукопись или нужные материалы проекта.

> [!TIP]
> При установке копируйте **всю папку навыка**. При ручной передаче сохраняйте
> названия справочников и объясняйте, к какому навыку они относятся: ссылки вида
> `references/...` не открывают автоматически файлы, которые не были переданы.

Это использование инструкций в контексте беседы. Оно не создаёт установленный
навык, не добавляет его в меню и не подключает всю коллекцию автоматически.

## Инструкция для агента

Этот раздел предназначен для агента, **которому пользователь поручил установку**.
Чтение README само по себе не является командой устанавливать файлы.

### 1. Определи запрос и возможности

- Источник: `https://github.com/Biryukovlex/story-skills-chatgpt-ru`; навыки находятся в `skills/`.
- Если пользователь выбрал навыки, установи только их. Если попросил установить коллекцию без уточнений, установи все 24.
- Учти инструкции текущего проекта, доступные инструменты и настройки обнаружения навыков.
- Уважай выбранную область установки. Если она не указана, для локального Codex предпочти пользовательскую установку; явный запрос «для этого проекта» означает проектную.

### 2. Выбери способ установки

**Если есть установщик навыков:** используй его по его инструкции. Передай репозиторий
и точные пути `skills/<skill-name>`. Установи выбранный набор и зафиксируй фактическую
директорию назначения.

**Если установщика нет, но есть файловый доступ в Codex:**

1. Получи репозиторий во временную папку или используй уже доступную проверенную копию. Зафиксируй коммит источника.
2. Определи поддерживаемую директорию: обычно `~/.agents/skills/` для пользователя или `.agents/skills/` внутри выбранного проекта.
3. Копируй каждую папку `skills/<skill-name>/` целиком. Не помещай всю коллекцию одним вложенным каталогом и не копируй только `SKILL.md`.
4. Сохраняй относительную структуру `agents/` и `references/`. Для одного навыка соседние 23 папки не требуются.

**Если среда не поддерживает установку папок:** подготовь [ручное использование](#ручное-использование)
и обозначь этот результат. Для штатного мобильного подключения нужен плагин;
не объявляй его созданным или установленным из этого репозитория.

### 3. Сохрани существующее

Проверь совпадения имён и путей до копирования. Идентичную установленную копию
можно пропустить. Отличающуюся копию не перезаписывай, если обновление не входит
в запрос; сохрани её и сообщи о конфликте. При разрешённом обновлении сохрани
локальные изменения доступным способом.

### 4. Проверь результат

- В каждой выбранной установленной папке есть `SKILL.md`, `agents/openai.yaml` и все её справочники.
- Локальные ссылки из инструкций разрешаются внутри этой папки.
- При наличии списка установленных навыков проверь обнаружение. Наличие файлов и появление навыка в клиенте — разные проверки.
- Для всей коллекции ожидаются **24 папки навыков**. Для выбранного набора сверяй точные имена, а не только число.
- Сообщи коммит источника, установленные имена, директорию, конфликты и пример вызова. Не называй установку завершённой, если выполнено лишь скачивание или ручная передача инструкций.

## Как используется контекст

Навык сначала учитывает запрос и применимые инструкции, затем находит относящиеся
к задаче материалы: главы, канон, планы, образцы стиля, отзывы, исследовательские
записи, изображения и подключённые источники.

В Codex это включает доступную рабочую папку и её инструкции, например `AGENTS.md`.
В ChatGPT Work — доступные материалы проекта, вложения, документы и подключённые
сервисы. Для сроков учитываются текущая дата, часовой пояс и условия адресата.

Поиск ограничивается задачей и выбранным проектом. Старый план, действующая рукопись
и новое предложение различаются; противоречие источников отмечается явно.
Материал запрашивается у пользователя после проверки доступных источников.
При отсутствии доступа навык работает с имеющимся и обозначает существенные пробелы.

**Самостоятельность навыка означает независимость от других навыков.** Она позволяет
использовать проектный контекст и инструменты текущего сеанса.


## Возможности и границы

- **Текст:** можно работать с отдельным отрывком, заметками или доступной рукописью.
- **Инструменты:** поиск, просмотр файлов, создание медиа и независимые запуски доступны только при наличии соответствующих средств. Их результаты не выдумываются.
- **Отзывы:** модельные читательские позиции обозначаются как симуляция и не заменяют реальных читателей.
- **Выпуск книги:** подготовка заявки или публикации не означает разрешения на отправку текста, принятие договора или расход бюджета.

Навыки помогают организовать работу; проверяйте факты, предложенные правки
и соответствие авторскому замыслу.
