# Story Skills для ChatGPT — русский язык

24 навыка для создания и редактирования художественных текстов. Адаптация
[danjdewhurst/story-skills](https://github.com/danjdewhurst/story-skills),
исходный коммит `33085ccc3ceb94a6ff9362cf499091123cdfb30d`.

## Что изменено

- Русские запросы распознаются в описаниях навыков; ответы и новая проза по умолчанию на русском.
- Добавлены нормы русской прозы, диалога, редактуры, рифмы и стихотворного размера.
- Для новых русских проектов используется `language: ru`; явный язык существующей рукописи сохраняется.
- Работа с отдельным текстом доступна прямо в беседе, без папки проекта и Story CLI.
- Добавлены русские названия, описания и примеры запросов в `agents/openai.yaml`.
- Сохранены исходные методики и справочники на английском. Это функциональная адаптация, а не полный перевод документации.

## Состав

В `skills/` находятся только навыки, их справочники и метаданные OpenAI.
Приложение, CLI, скрипты, зависимости, сайт и конфигурация Claude не включены.
Корневые `README.md` и `LICENSE` описывают адаптацию и сохраняют лицензию автора.

Каждая папка навыка содержит `SKILL.md`, `agents/openai.yaml` и `references/`.
Правила русского языка продублированы внутри каждого навыка, чтобы сохраняться
при отдельном копировании. Другие перекрёстные справочники доступны в полной коллекции.

## Использование

В среде ChatGPT с поддержкой устанавливаемых навыков импортируйте нужную папку
через доступный интерфейс навыков. Само размещение на GitHub не устанавливает
навыки и не включает их во всех версиях ChatGPT. Репозиторий не является
плагином и не содержит его манифеста.

Если импорт навыков недоступен, приложите `SKILL.md` и нужные справочники к беседе
или добавьте их как материалы проекта, затем явно попросите следовать навыку.
Это ручная передача инструкций, без автоматического подключения всей коллекции.

Примеры запросов:

- «Используй premise-workshop: помоги придумать конфликт для рассказа о смотрителе маяка».
- «Используй line-editing: отредактируй этот русский отрывок, сохрани голос автора».
- «Используй verse-craft: разбери размер и рифмовку этого стихотворения».
- «Используй reader-panel: оцени первую страницу с нескольких читательских позиций».

В Codex папки из `skills/` можно установить в поддерживаемую директорию навыков.
Синтаксис явного вызова зависит от клиента; `agents/openai.yaml` содержит
примеры с `$skill-name`.

## Инструменты и ограничения

Команды `story …` в сохранённых справочниках относятся к отдельно устанавливаемому
исходному Story CLI. Для работы с текстом они необязательны. Без CLI навыки
выполняют смысловую проверку чтением и явно отличают её от автоматических проверок.
Экспорт, звук, браузер и независимые агенты доступны только при наличии таких
инструментов в текущей среде. Статические файлы не гарантируют качество каждого
ответа модели; проверяйте предложенные правки и факты.
