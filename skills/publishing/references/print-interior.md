# Печатный и электронный макет

Для печати согласуй формат страницы, поля, корешковое поле, шрифты, колонтитулы, переносы и требования типографии. Обложку рассчитывай по фактическому блоку и параметрам производства.

Для электронной версии проверь оглавление, навигацию, изображения, примечания и поведение при смене размера текста. Развёрнутый текст и фиксированная страница требуют разных решений.

После экспорта открывай сам результат. Проверяй шрифты, пропуски, спецсимволы, разрывы и содержание. Для печати желателен физический пробный экземпляр. Без готового файла и просмотра не объявляй макет проверенным.
