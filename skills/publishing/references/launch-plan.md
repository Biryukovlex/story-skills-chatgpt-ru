# План выпуска и продвижения

Раздели подготовку, выпуск и последующее наблюдение. Для задачи укажи исполнителя, срок, зависимость, бюджет и критерий готовности.

Планируй описание книги, обложку, страницу продажи, материалы для читателей и доступные каналы связи. Рекламный тест должен иметь ограниченный бюджет, аудиторию, показатель и условие остановки.

Цену сравнивай с релевантными изданиями с учётом формата, территории, комиссий и целей автора. Не обещай окупаемость по аналогии с чужим успехом. После запуска отделяй наблюдаемые данные от предположений о причинах.
