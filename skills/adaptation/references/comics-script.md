# Комикс: страницы и кадры

Планируй страницу как последовательность изменений внимания. В кадре описывай один изображаемый момент; несколько последовательных действий разделяй. Для каждого кадра укажи композиционный смысл, действие, реплики, подписи и значимые звуки.

Шаблон: «Страница → кадр → что видно → кто говорит → текст». Проверяй порядок чтения и место под баллоны. Число кадров выбирай по ритму, а не по постоянной квоте.

Поворот страницы может скрывать раскрытие или менять масштаб. Избегай текста, который только повторяет рисунок, и рисунка, без которого теряется причинность, но который сценарий не описал.
