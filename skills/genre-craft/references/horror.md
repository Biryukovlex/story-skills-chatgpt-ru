# Хоррор

Различай ожидание угрозы, непосредственный ужас и телесное отвращение. Выбирай их сочетание по задаче, не заменяя атмосферу постоянным усилением жестокости.

Дай читателю опору в обычном, затем нарушай знакомые закономерности. Правила угрозы могут оставаться неполными, но поведение опасности должно быть достаточно последовательным для напряжения.

Чередуй давление с восстановлением, чтобы следующий удар ощущался. Проверь, что действия героя правдоподобны при доступных ему сведениях; глупость ради продолжения опасности ослабляет страх.
