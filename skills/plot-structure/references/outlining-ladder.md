# Глубина планирования

Начни с минимально полезного уровня: одно предложение о конфликте; абзац об изменении; список поворотов; последовательность сцен; подробный план.

Увеличивай детализацию, если она помогает решить реальную неопределённость. Для каждой сцены достаточно цели, препятствия, изменения и связи со следующей.

При перепланировке отделяй неизменяемые решения автора от пробных вариантов. План должен обслуживать письмо; не требуй заполненной биографии всех участников до первого черновика.
