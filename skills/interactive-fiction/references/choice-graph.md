# Граф выборов

Таблица узлов: обозначение → цель сцены → варианты → условие → изменение → следующий узел. Назначай обозначения так, чтобы перестановка текста не ломала переходы.

Выбор может менять маршрут, ресурс, отношение, сведения или способ самовыражения. Если последствия одинаковы, не изображай такой выбор как крупную развилку.

Ветви могут расходиться и сходиться. При схождении сохраняй значимые последствия, иначе предыдущий выбор обесценивается. Для цикла определи изменение состояния и выход. Концовки должны быть достижимы из начала при выполнимых условиях.
