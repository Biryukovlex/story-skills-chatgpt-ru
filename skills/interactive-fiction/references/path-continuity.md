# Непротиворечивость маршрутов

Проверяй состояние вдоль маршрута, а не по порядку размещения узлов. Состояние включает знания, живых и погибших персонажей, предметы, отношения, время и израсходованные ресурсы.

Для общего узла сравни входящие состояния. Если герой получает ключ только на одном пути, общий текст не может без условия описывать открытие двери этим ключом.

При большом графе не объявляй проверку полной по нескольким примерам: укажи покрытие и непроверенные сочетания. Для автоматической проверки нужны исполняемые правила и реальный запуск; наличие таблицы переходов этого не доказывает.
