# Учёт подач

Таблица: произведение и версия → адресат → ссылка на требования → дата проверки → пакет → статус → фактическая дата отправки → ожидаемый срок → ответ → действие.

Статусы: готовится, готово к отправке, отправлено, получен запрос, принято, отказ, отозвано. Заполняй фактические даты только по подтверждённым событиям.

Перед напоминанием проверь правила адресата и обещанный срок. Не отправляй повторные письма автоматически и не отмечай молчание как отказ без основания.
