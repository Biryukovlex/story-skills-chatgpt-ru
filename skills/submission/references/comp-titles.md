# Сопоставимые книги

Выбирай произведения по аудитории, структуре, настроению, теме или форме. Для каждого сравнения объясни одну конкретную близость и существенное отличие.

Проверяй автора, название, время выхода и фактическую основу сравнения. Если книга не прочитана, не приписывай ей подробную структуру по одной аннотации.

Сравнение помогает понять место проекта; оно не является прогнозом продаж. При недостатке данных предложи критерии поиска и кандидатов с явно обозначенным статусом проверки.
