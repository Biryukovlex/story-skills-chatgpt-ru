# Рассказ, журнал и конкурс

Проверь тему, жанр, язык, объём, сроки, статус ранее опубликованного текста и правила параллельной подачи. Публикация в открытом доступе может иметь значение по условиям конкретного адресата.

Уточни, какие права запрашиваются, на какой срок и для каких форматов. Не считай удаление текста из сети доказательством отсутствия прошлой публикации.

Для сборника проверь самостоятельность рассказов, порядок чтения и права на уже выходившие тексты. Даты и условия бери из актуального официального объявления, а не из старого списка площадок.
