# Место

Название; функция в истории; расположение; доступ; власть; жители; приметные ощущения; опасности; ресурсы; связи с другими местами.

Выбирай детали по восприятию конкретного героя: знакомый житель и чужак замечают разное. Прошлое места должно проявляться в настоящих ограничениях или следах.

Фиксируй состояние по времени: разрушенный мост и открытая переправа не могут одновременно обеспечивать один маршрут без объяснения.
