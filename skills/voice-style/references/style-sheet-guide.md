# Стилевой паспорт

Зафиксируй повествовательное лицо, время, дистанцию, регистр, характерный ритм, тип образов, юмор и предел объяснений. Для каждого существенного вывода приведи короткий пример из образца.

Добавь решения по именам, обращениям, «ё», цитатам и диалогу, если они нужны для согласованности. Речевые особенности персонажей храни отдельно от общего голоса повествования.

Различай «наблюдается в образце» и «предлагается для нового текста». Обновляй паспорт при осознанном изменении замысла; он помогает автору, а не запрещает эксперимент.
