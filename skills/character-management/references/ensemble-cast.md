# Ансамбль персонажей

Определи, кто удерживает внимание в каждой сюжетной линии. Для каждого значимого участника запиши собственную цель, доступные сведения, уникальную функцию и вклад в общий конфликт.

Переплетай линии через последствия, а не только через чередование глав. Проверяй, как событие одной линии изменяет возможности другой.

Если два персонажа выполняют одну функцию, сравни варианты объединения и сохранения. При объединении проверь голос, отношения, хронологию и доступ к сведениям. Равный объём текста не обязателен; самостоятельность выбора важнее симметрии.
