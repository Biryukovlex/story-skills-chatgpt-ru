# Карточка персонажа

Имя и формы обращения; роль; желание сейчас; долгосрочная цель; потребность; ограничивающее убеждение; страх; ресурсы; цена неудачи.

Добавь поведенческое противоречие, значимый эпизод прошлого и выбор, способный изменить героя. Внешность отбирай по узнаваемости и функции, а не заполняй обязательный список.

Для голоса зафиксируй привычную длину фразы, словарь, степень прямоты, обращения и то, о чём персонаж умалчивает. Приложи две короткие реплики в разных обстоятельствах. Биографические даты и сведения других героев сверяй по тексту.
